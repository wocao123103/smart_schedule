# 智能日程助手

> 一个「浏览器打开就能用、数据只留在自己电脑上」的日程与待办管理工具。
> 五视图 · 四主题 · AI 对话式录入 · 自动规则 · Word/Excel 导入 · Excel/CSV/日历导出。

**在线体验：** <https://wocao123103.github.io/smart_schedule/>
**下载安装包：** [安装_智能日程助手.zip](./安装_智能日程助手.zip)（解压后运行 exe）

| 项目 | 说明 |
|---|---|
| 版本 | v2.3.0 |
| 技术 | 原生 HTML / CSS / JavaScript（无框架、无构建依赖） |
| 后端（本地版） | Python 标准库 `http.server` + `sqlite3` |
| 数据 | 网页版存 `localStorage`，本地版存 SQLite，**都不上传服务器** |
| 体积 | 单页 `index.html` 约 1.7 MB，安装包 21.7 MB |

## 两个版本，同一套界面

| | 网页版（在线） | 本地部署版（exe） |
|---|---|---|
| 打开方式 | 浏览器访问 GitHub Pages | 双击安装包 → 桌面快捷方式 |
| 数据位置 | 浏览器 `localStorage` | 本地 SQLite（`data/app.db`） |
| 是否需要安装 | 不需要 | 需要（一次） |
| 适用场景 | 手机随手记、换设备能用 | 数据要留在本机、离线也能用 |
| 额外能力 | 可装到主屏（PWA）、离线打开 | 控制面板一键起服务、自动备份、一键初始化 |

两者的界面、功能、快捷键完全一致——**本地版只是把「浏览器存储」换成了「自己的数据库」**。

## 功能一览

### 视图与交互

- **列表 / 日历 / 看板 / 统计 / 垃圾箱** 五个视图，一键切换
- 优先级 1–5 色标（1 绿 → 5 红）、状态、截止时间、地点、标签、子任务
- **四套主题**：深色极光标准版、青少年版、老年版（大字号高对比）、二次元版
- 搜索（260 ms 防抖）、状态/优先级/标签筛选、批量勾选与批量删除
- 垃圾箱支持恢复、彻底删除、一键清空（二次确认）
- 手机端：底部 5 标签 + 悬浮「＋」，全屏抽屉

### AI 助手（设置里填自己的 Key）

| 页签 | 作用 |
|---|---|
| **智能添加** | 一句话 → 拆成多条日程；**可以接着对话修改**，结果逐条可编辑，勾选后入库 |
| 智能排序 | 按优先级 + 截止时间给出建议顺序，一键应用 |
| 总结 | 完成率、拖延项、下周重点 |
| 拆解 | 大任务拆成 3–6 个可执行子步骤，直接建成带子任务的日程 |
| 对话 | 自由问答 |

支持 OpenAI / DeepSeek / 通义千问 / Kimi / 智谱 GLM / 任意 OpenAI 兼容接口，可填 CORS 代理。
**没填 Key 或调用失败时会走本地规则兜底**，界面上会明确标注「本地兜底」，不会假装成功。

### 导入与导出

- 导入：`.docx`（Word）、`.xlsx`（Excel）、`.csv`、`.json`、`.md`、`.txt`、图片截图识别
- 导出：Excel（`.xlsx`）、CSV、系统日历（`.ics`）、本周长图（PNG）
- 原版 JSON 备份可回灌，重复导入按 id 合并，不会产生重复条目

### 自动规则（本地确定性执行，不调模型）

| 条件 | 处理 |
|---|---|
| 截止日期早于「今天 − 5 天」且未完成 | 自动标记完成 |
| 截止日期早于「今天 − 30 天」且未完成 | 自动删除 |
| 标签含「课程」或内容是课程 | 按上课时间自动流转 待办 → 进行中 → 已完成 |

触发时机：启动时、每 60 秒、页面重新可见时。

## AI 录入的正确用法

1. 点侧栏「AI 助手」→「智能添加」
2. 说一句话：`明天下午三点交数据结构实验报告，重要；周五体测记得带学生证`
3. AI 拆成多条，右侧「待录入」里**每一条都能直接改**（标题 / 日期 / 时间 / 优先级）
4. 不满意就再说一句：`第二条改成周五上午九点，优先级提到紧急` —— AI 会改，你确认后再点「添加勾选的」

**日期口径**（前后端各实现一套，互为兜底）：

| 你说 | 结果 |
|---|---|
| `3月5日`（没写年份） | 当前年份的 3 月 5 日 |
| `明天` / `后天` / `大后天` | 以今天为基准 +1 / +2 / +3 天 |
| `周五` | **未来最近**的周五（今天就是周五则算下周五） |
| `下周一` | 下一周的周一 |
| `11.4` / `11-04` | 当前年份 11 月 4 日 |

其他细节：标题+日期相同的条目入库前自动去重；录入后可点底部「撤销」把这批删掉；支持拖动或 `↑ ↓` 调整顺序。

## 快速开始

### 方式一：在线用（最简单）

打开 <https://wocao123103.github.io/smart_schedule/>
手机上可以「添加到主屏幕」，当作 App 用，支持离线打开。

### 方式二：本地部署版（数据留在自己电脑）

1. 下载 [安装_智能日程助手.zip](./安装_智能日程助手.zip) 并解压
2. 双击 `安装_智能日程助手.exe`，选择安装位置（会自动识别旧版本并覆盖升级，**保留数据**）
3. 桌面出现快捷方式 → 双击 → 控制面板里点「打开网页」

控制面板四个按钮：

| 按钮 | 作用 |
|---|---|
| 打开网页 | 打开 `http://127.0.0.1:8000/` |
| 数据初始化 | 清空所有日程（清空前自动备份） |
| 备份 | 立刻存一份快照 |
| 结束运行 | 停掉临时服务，网址失效 |

数据在安装目录的 `data/app.db`，卸载时可选择「保留数据」或「一起删除」。

### 方式三：源码运行

```bash
# 网页版：直接开 index.html 也行，但建议起个静态服务（PWA 需要 http 协议）
python -m http.server 8080

# 本地部署版（Python 3.10+，无需第三方库）
python panel.py
```

## 常见问题

**Q：装的时候被杀毒软件拦了？**
安装包是 PyInstaller 打包的，360 等常把它误判成「加壳程序」。弹窗里选「允许 / 添加信任」即可，也可以在「木马查杀 → 隔离区」里恢复并信任。介意的话直接用网页版，功能完全一样。

**Q：本地版提示 8000 端口被占用？**
先关掉正在运行的面板（或上次没退干净的进程），再重新打开。控制面板只用 8000 这一个端口。

**Q：数据存在哪？换电脑怎么迁移？**
- 网页版：浏览器 `localStorage`，可在「设置 → 导出数据」导出 JSON，新设备再导入
- 本地版：`data/app.db`，整个文件夹拷走即可；同一目录下有 `backups/`，随时能恢复

**Q：AI 用不了？**
去「设置 → 大模型接入」填自己的 API Key（只存本地）。没 Key 时所有 AI 功能会降级成本地规则，界面会标注「本地兜底」。

**Q：在线版打开是空白？**
可能是浏览器缓存了旧版 Service Worker：按 `Ctrl + F5` 强刷，或清除该站点数据后重进。
