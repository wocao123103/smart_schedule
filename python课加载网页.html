FAQ

几个常见问题

装的时候被杀毒软件拦了怎么办？

安装包是 PyInstaller 打的，360 等常把它误判成加壳程序。选「允许 / 添加信任」即可，也可以在「隔离区」里恢复并信任。介意的话直接用在线版，功能一样。

提示 8000 端口被占用？

先关掉正在运行的面板（或上次没退干净的进程）再打开。控制面板只占 8000 这一个端口。

数据存在哪？换电脑怎么迁移？

本地版在安装目录的 data/app.db，把整个文件夹拷走即可；旁边还有 backups/。在线版在浏览器 localStorage，可以用「设置 → 导出数据」导出 JSON。

没有 API Key 还能用吗？

能。没配 Key 时所有 AI 功能降级成本地规则（关键词 + 正则），界面上会明确标「本地兜底」，不会假装成功。
